# Погода · ТЕХНіКА

Кастомна картка погоди для Home Assistant (Lovelace) в оформленні серії **ТЕХНіКА**.

**Версія: 0.1.1 Alpha.** Картку перевірено в браузері з демонстраційними даними. Сумісність із конкретним джерелом погоди потрібно перевірити у вашому Home Assistant.

## Можливості

- Поточна температура, стан погоди та температура «відчувається як».
- Вітер, вологість і атмосферний тиск.
- Прогноз на найближчі години та дні; підтримка прогнозу «день/ніч».
- Шкала ймовірності опадів на наступні 24 години.
- Деталі поточної погоди й прогнозу по натисканню, без зміни висоти картки.
- Палітри **Олива** та **Графіт**, світле й темне оформлення.
- Режим **Авто**, що використовує тему Home Assistant.
- Спільний перемикач рамки для сумісних карток серії ТЕХНіКА.
- Візуальний редактор і автоматичний вибір сутності `weather.*`.
- Особисті налаштування вигляду в профілі HA з локальним кешем.
- Український інтерфейс. Дати та час — `Europe/Kyiv`.

Один JS-файл, без зовнішніх бібліотек і CDN.

## Джерело погоди

У Home Assistant має бути налаштована інтеграція, що створює сутність `weather.*`.

Картка використовує дані цієї сутності та підписки на її прогнози. Наявність погодинного, добового прогнозу, ймовірності опадів та інших показників залежить від інтеграції. Якщо показника немає, відображається риска або відповідне повідомлення.

Картка не потребує окремого API-ключа і не звертається до погодного сервісу напряму. Інтернет-доступ та облікові дані самого джерела залежать від обраної інтеграції HA.

## Встановлення через Магазин Home Assistant

Починаючи з **v0.1.1**, маніфест `hacs.json` включено до випуску. У v0.1.0 його немає, тому для встановлення через магазин обирайте v0.1.1 або новішу версію.

1. Відкрийте Магазин у Home Assistant та оберіть **Додати з посилання GitHub**.
2. Вставте адресу репозиторію:

   ```text
   https://github.com/hrudkaav/pogoda-tehnika-card
   ```

3. Натисніть **Додати**, відкрийте картку «Погода · ТЕХНіКА» та встановіть актуальну версію.
4. Оновіть сторінку браузера або перезапустіть застосунок HA, щоб завантажити модуль картки.
5. У режимі редагування панелі додайте **Погода · ТЕХНіКА** зі списку карток або через YAML:

   ```yaml
   type: custom:pogoda-tehnika-card
   ```

Магазин додає ресурс картки автоматично для панелей, ресурси яких керуються через інтерфейс. Якщо ресурси задані в YAML, скористайтеся шляхом, який покаже діалог встановлення. Очікуваний шлях файла:

```yaml
resources:
  - url: /local/community/pogoda-tehnika-card/pogoda-tehnika-card.js
    type: module
```

### Якщо використовуєте HACS

У HACS відкрийте меню **⋮ → Користувацькі репозиторії / Custom repositories**, додайте ту саму адресу та оберіть тип **Dashboard / Панель** (у деяких версіях — **Lovelace / Plugin**). Знайдіть картку й натисніть **Download / Завантажити** або **Install / Встановити**. Після цього оновіть браузер і додайте картку на панель.

Якщо раніше ви встановлювали картку вручну, перевірте список ресурсів: один і той самий модуль має завантажуватися лише один раз. Залиште ресурс, створений магазином або HACS, та приберіть старий ручний запис.

## Встановлення вручну

1. Завантажте [pogoda-tehnika-card.js](https://github.com/hrudkaav/pogoda-tehnika-card/blob/main/pogoda-tehnika-card.js) кнопкою **Download raw file**. Збережіть саме JS-файл, а не HTML-сторінку GitHub.
2. Покладіть його в папку `/config/www/` вашого Home Assistant. Якщо папки `www` немає, створіть її. Якщо створюєте її вперше, перезапустіть HA.
3. У ресурсах панелі Lovelace додайте:

   ```text
   URL: /local/pogoda-tehnika-card.js?v=0.1.1
   Тип: JavaScript-модуль
   ```

   Зазвичай ресурси доступні через **Налаштування → Панелі → меню ⋮ → Ресурси**. За потреби увімкніть розширений режим у своєму профілі.

4. Оновіть сторінку браузера й додайте картку через меню вибору карток або вручну:

   ```yaml
   type: custom:pogoda-tehnika-card
   ```

Перша доступна сутність погоди обереться автоматично. Якщо маєте кілька джерел, оберіть потрібне у візуальному редакторі.

Можна вказати сутність і місце явно:

```yaml
type: custom:pogoda-tehnika-card
entity: weather.forecast_home
city: Миколаїв
```

Замініть `weather.forecast_home` на вашу сутність.

Для панелі, ресурси якої задані в YAML, відповідний запис ресурсу має вигляд:

```yaml
resources:
  - url: /local/pogoda-tehnika-card.js?v=0.1.1
    type: module
```

## Налаштування картки

Базові параметри доступні у візуальному редакторі. Приклад повної конфігурації:

```yaml
type: custom:pogoda-tehnika-card
entity: weather.forecast_home
title: Погода
city: Миколаїв
palette: olive
mode: auto
hours: 6
days: 5
show_hourly: true
show_precipitation: true
show_daily: true
```

| Параметр | Типове значення | Призначення |
| --- | --- | --- |
| `entity` | Автоматично | Сутність `weather.*` |
| `title` | `Погода` | Заголовок |
| `city` | Назва сутності | Назва міста або місця |
| `palette` | `olive` | `olive` — Олива, `graphite` — Графіт |
| `mode` | `auto` | `auto`, `light` або `dark` |
| `hours` | `6` | Кількість годин: ціле число від 3 до 8 |
| `days` | `5` | Кількість днів або періодів «день/ніч»: від 3 до 7 |
| `show_hourly` | `true` | Погодинний прогноз |
| `show_precipitation` | `true` | Шкала ймовірності опадів |
| `show_daily` | `true` | Добовий прогноз або прогноз «день/ніч» |
| `preferences_id` | ID сутності | Необов'язковий окремий ідентифікатор особистих налаштувань вигляду |

### Особистий вигляд

Натисніть шестерню на картці, щоб змінити палітру, оформлення та рамку.

Палітра й оформлення з редактора або YAML задають початковий вигляд. Особистий вибір через шестерню має пріоритет і зберігається у профілі користувача HA. У разі тимчасової помилки збереження використовується локальний кеш із повторною спробою синхронізації.

Картки однієї погодної сутності використовують спільні особисті налаштування. Для окремого вигляду кількох екземплярів задайте різні `preferences_id`.

Рамка синхронізується між сумісними картками ТЕХНіКА в одному браузері та між вкладками одного походження. Спільний локальний перемикач має пріоритет над значенням рамки, завантаженим із профілю. У застосунку й іншому браузері локальні налаштування можуть відрізнятися.

### Шкала опадів

Шкала починається з поточної години й охоплює наступні 24 години. Показані значення — ймовірність опадів у відсотках, а не їхня кількість.

- **0%** — джерело прогнозує нульову ймовірність.
- **1–69%** — смугасте жовте заповнення.
- **70–100%** — суцільне жовте заповнення.
- **Немає даних** — окреме позначення, яке не означає 0%.

Біла риска позначає поточний час. Натисніть на сегмент, щоб відкрити деталі. Якщо джерело передає кількість опадів, але не їхню ймовірність, кількість може відображатися в погодинному прогнозі; відсотки з неї не обчислюються.

## Оновлення

Замініть `/config/www/pogoda-tehnika-card.js` новим файлом і змініть параметр `v` в URL ресурсу на номер нової версії. Після цього оновіть сторінку або перезапустіть застосунок HA.

## Якщо картка не працює

- **Has no hacs.json in its root:** встановлюйте v0.1.1 або новішу версію; у v0.1.0 маніфест відсутній. Якщо помилка залишилася після публікації виправлення, оновіть дані репозиторію в магазині й повторіть додавання.
- **Custom element doesn't exist:** перевірте ім'я файла, URL ресурсу, тип **JavaScript-модуль** та оновіть кеш браузера.
- **Сутність не знайдено:** оберіть чинну сутність `weather.*` у редакторі.
- **Немає прогнозу:** перевірте, чи надає ваша інтеграція відповідний тип прогнозу.
- **Дані недоступні:** перевірте стан погодної інтеграції у Home Assistant.

Про проблеми можна повідомляти в [Issues](https://github.com/hrudkaav/pogoda-tehnika-card/issues). Додайте версію HA, назву погодної інтеграції, конфігурацію картки й опис поведінки. Перед публікацією приберіть із прикладів особисті дані та секрети.
