# Погода · ТЕХНіКА

Кастомна картка погоди для Home Assistant (Lovelace) в оформленні серії **ТЕХНіКА**.

**Версія: 0.3.0 Alpha.** Картку перевірено в браузері з демонстраційними даними. Роботу з вашим джерелом погоди потрібно перевірити у Home Assistant.

## Два екрани одного розміру

**Головний екран — макет №3, «Акцент на температурі»:**

- Угорі лише назва погодної сутності та кругла кнопка **Т**.
- Велика температура ліворуч, значок погоди праворуч.
- Нижче вітер, вологість і ймовірність опадів, якщо джерело передає ці дані.
- Погодинний прогноз одним рядком.

**Стрілка вниз** перемикає картку на прогноз на п'ять днів рядками. **Стрілка вгору** або **Escape** повертають поточну погоду. Обидва екрани мають однакову висоту: перемикання не зсуває інші картки на панелі.

Натисніть температуру, годину або день, щоб переглянути додаткові показники у вікні. Порожні показники приховуються. Вікно закривається кнопкою **×**, натисканням поза ним або клавішею **Escape**.

## Три стилі значків і теми

Натисніть круглу кнопку **Т** у верхньому правому куті картки.

- **Пласкі** — чіткі геометричні значки.
- **М’який об’єм** — значки з м'яким об'ємним оформленням.
- **Матове скло** — напівпрозоре оформлення з підсвіченими контурами.

Усі значки вбудовані в єдиний JS-файл як SVG. Додаткові файли, зовнішні бібліотеки й CDN не потрібні.

Палітри: **Олива / Графіт**. Оформлення: **Світла / Темна / Авто**. У режимі **Авто** використовується тема Home Assistant. Початкові значення — пласкі значки, Олива та Авто.

Особистий вибір стилю значків, палітри й оформлення зберігається у профілі користувача HA та кешується в браузері. Він має пріоритет над початковими значеннями в редакторі або YAML.

Перемикач рамки спільний для сумісних карток серії ТЕХНіКА в одному браузері та між вкладками одного походження. Спільне локальне значення має пріоритет над значенням рамки з профілю; інший браузер або застосунок може мати своє локальне значення.

## Назва й джерело погоди

Картка відображає назву вибраної сутності `weather.*` з Home Assistant. Щоб у заголовку було «Миколаїв» або «Семенівка», назвіть відповідну погодну сутність саме так. Зміна її назви автоматично відображається на обох екранах.

Перейменування сутності змінює підпис, а місце прогнозу визначає погодна інтеграція. Картка не використовує геолокацію телефона, не виконує запитів до геокодерів і не потребує власного API-ключа.

Температура, вітер, вологість і прогнози надходять із погодної сутності та підписок HA. Доступність показників залежить від інтеграції. Наприклад, Met.no може надавати погоду для розташування, налаштованого в Home Assistant.

Ймовірність опадів береться з поточного показника сутності, якщо він є, або з найближчої доступної години прогнозу. Час цього прогнозу видно в підказці показника. Значення **0%** зберігається, а відсутнє значення приховується. Кількість опадів у міліметрах не перетворюється на відсотки.

Добовий екран показує до п'яти різних календарних днів у часовому поясі **Europe/Kyiv**. Якщо джерело дає лише прогноз «день/ніч», періоди групуються за календарним днем, а температурний діапазон обчислюється за доступними періодами. Окремі періоди можна переглянути в деталях дня. Картка не доповнює відсутні дні вигаданими даними.

## Встановлення через Магазин Home Assistant

1. Відкрийте Магазин та оберіть **Додати з посилання GitHub**.
2. Вставте адресу:

   ```text
   https://github.com/hrudkaav/pogoda-tehnika-card
   ```

3. Додайте репозиторій, відкрийте **Погода · ТЕХНіКА** та встановіть актуальну версію.
4. Оновіть сторінку браузера або перезапустіть застосунок HA.
5. У редакторі панелі додайте картку зі списку або вручну:

   ```yaml
   type: custom:pogoda-tehnika-card
   ```

Перша доступна погодна сутність вибереться автоматично. За потреби змініть її у візуальному редакторі.

Магазин додає ресурс автоматично, коли ресурси панелі керуються через інтерфейс. Для ресурсів у YAML використовуйте шлях із діалогу встановлення. Очікуваний запис:

```yaml
resources:
  - url: /local/community/pogoda-tehnika-card/pogoda-tehnika-card.js
    type: module
```

### HACS

У меню HACS **⋮ → Користувацькі репозиторії / Custom repositories** додайте ту саму адресу як **Dashboard / Панель** (у деяких версіях — **Lovelace / Plugin**). Знайдіть картку, встановіть її й оновіть браузер.

### Ручне встановлення

1. Завантажте `pogoda-tehnika-card.js` із [актуального релізу](https://github.com/hrudkaav/pogoda-tehnika-card/releases).
2. Покладіть файл у `/config/www/`. Якщо створюєте папку `www` уперше, перезапустіть HA.
3. Додайте ресурс `/local/pogoda-tehnika-card.js?v=0.3.0` як **JavaScript-модуль**.
4. Оновіть браузер і додайте картку на панель.

Якщо переходите з ручного встановлення на HACS / Магазин, залиште в ресурсах один запис модуля, щоб він не завантажувався двічі.

## Налаштування

```yaml
type: custom:pogoda-tehnika-card
entity: weather.forecast_home
icon_style: flat
palette: olive
mode: auto
hours: 6
show_hourly: true
show_precipitation: true
show_daily: true
```

Замініть `weather.forecast_home` на вашу сутність. Параметри доступні й у візуальному редакторі.

| Параметр | Початкове значення | Призначення |
| --- | --- | --- |
| `entity` | Автоматично | Погодна сутність `weather.*` |
| `icon_style` | `flat` | `flat` — Пласкі, `soft` — М’який об’єм, `glass` — Матове скло |
| `palette` | `olive` | `olive` або `graphite` |
| `mode` | `auto` | `auto`, `light` або `dark` |
| `hours` | `6` | Кількість годин у рядку: ціле число від 3 до 8 |
| `show_hourly` | `true` | Погодинний рядок на головному екрані |
| `show_precipitation` | `true` | Показник імовірності опадів на головному екрані |
| `show_daily` | `true` | Перемикання на екран п'ятиденного прогнозу |
| `preferences_id` | ID сутності | Окремий ідентифікатор особистих налаштувань для кількох екземплярів |

У конфігураціях попередніх версій `title`, `city` та `days` можуть залишатися, але вони більше не визначають заголовок і кількість днів. Заголовок завжди береться з погодної сутності, а добовий екран показує до п'яти календарних днів. Параметр `show_precipitation` тепер керує компактним показником імовірності замість колишньої 24-годинної шкали.

## Оновлення й допомога

У HACS / Магазині встановіть оновлення та оновіть браузер через **Ctrl + F5** або перезапустіть застосунок HA. Для ручного встановлення замініть JS-файл і номер `v` у ресурсі.

- **Custom element doesn't exist:** перевірте URL ресурсу, тип **JavaScript-модуль** і кеш браузера.
- **Has no hacs.json in its root:** використовуйте v0.1.1 або новішу версію; у v0.1.0 маніфесту не було.
- **Назва не відповідає місту:** перейменуйте вибрану погодну сутність у HA та перевірте її місце прогнозу в інтеграції.
- **Немає прогнозу або показника:** перевірте, чи передає їх погодна інтеграція. Недоступні прогнози мають відповідне повідомлення.

Про проблеми повідомляйте в [Issues](https://github.com/hrudkaav/pogoda-tehnika-card/issues). Додайте версію HA, погодну інтеграцію, конфігурацію картки та опис поведінки.
