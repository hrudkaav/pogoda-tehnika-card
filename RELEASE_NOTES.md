Виправлення встановлення через HACS / Магазин Home Assistant. Картка залишається альфа-версією для тестування.

- Додано обов'язковий маніфест `hacs.json` у корінь репозиторію.
- У маніфесті вказано назву картки, JS-файл у корені та відображення README для HACS.
- Усунуто причину повідомлення «has no hacs.json in its root» під час додавання репозиторію.
- README доповнено інструкціями для Магазину HA та HACS.

Логіка й оформлення картки відповідають попередньому випуску. Перевірено структуру пакета, JSON і JavaScript. Встановлення у вашому Home Assistant потрібно перевірити після публікації.
