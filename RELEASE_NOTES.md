Перший публічний випуск картки «Погода · ТЕХНіКА» для Home Assistant. Альфа-версія для тестування.

- Поточна погода, температура «відчувається як», вітер, вологість і тиск.
- Погодинний, добовий прогноз і прогноз «день/ніч» залежно від джерела.
- Шкала ймовірності опадів на наступні 24 години та деталі по натисканню.
- Палітри «Олива» й «Графіт», світле, темне та автоматичне оформлення.
- Спільний перемикач рамки для сумісних карток ТЕХНіКА.
- Візуальний редактор, автоматичний вибір сутності погоди та особисті налаштування в профілі HA.
- Український інтерфейс, київський час і адаптивний вигляд.
- Автоматичне створення GitHub Release з JS-файлом через GitHub Actions.

Перевірено в браузері на тестових даних. Роботу з конкретною погодною інтеграцією потрібно перевірити у вашому Home Assistant. Інструкція встановлення — у README.
